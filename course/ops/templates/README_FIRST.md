# ハンズオンのご案内
本サーバーは、生成AIへの攻撃や防御を体験できるハンズオン環境です。
ハンズオンは、下記場所に存在する「Jupyter notebook」にて体験することができます。
`student_workspace/notebooks/`

まずは、下記ファイルを開き、指示にしたがってハンズオンを体験していきましょう。
`student_workspace/notebooks/10_prompt_leaking.ipynb`

# ⚠️注意
最初の実行時は、サーバーの起動に最大10分程度時間がかかります。

# 編集可能な場所
ハンズオンを進める際、防御の体験時は下記ディレクトリ内のファイルを編集してください。
- `student_workspace/edit_targets/`

# 編集しない場所
下記ディレクトリはハンズオン用の環境に関するソースコードが格納されており、編集はしないでください。
- `no_edit_Broken_LLM_Integration_App/`

ソースコード自体は、下記にてOSSとして公開されています。
https://github.com/13o-bbr-bbq/Broken_LLM_Integration_App
